# 2do Torneo Virtual de PVP en Montemorelos 🏆

Este repositorio contiene la página web oficial (landing page) con la información, reglas y formato del **2do Torneo Virtual de PVP de Pokémon GO** para la comunidad de Montemorelos, organizado por Arkev.

## 🌟 Características de la página

*   **Diseño Premium:** Estilo "dark mode" con efecto glassmorphism, inspirado en las retransmisiones competitivas oficiales de Pokémon.
*   **Totalmente Responsivo:** Adaptable a dispositivos móviles, tablets y computadoras de escritorio.
*   **Animaciones:** Efectos de aparición (scroll reveal) al desplazarse por el reglamento.
*   **Sin Dependencias:** Construido únicamente con HTML5 y Vanilla CSS3, lo que garantiza tiempos de carga ultrarrápidos.

## 🚀 Publicación con GitHub Pages

Este proyecto está listo para ser publicado usando **GitHub Pages** directamente desde la rama principal (`main` o `master`).

Para habilitarlo:
1. Ve a la pestaña **Settings** (Configuración) de este repositorio en GitHub.
2. En el menú lateral izquierdo, haz clic en **Pages**.
3. En la sección "Build and deployment", selecciona **Deploy from a branch**.
4. Elige tu rama principal (ej. `main`) y la carpeta `/ (root)`.
5. Haz clic en **Save**. En un par de minutos, tu sitio estará en vivo y disponible a través de una URL proporcionada por GitHub (ej. `https://[tu-usuario].github.io/torneoPVP`).

## 📁 Estructura del proyecto

*   `index.html`: Estructura y contenido de la página.
*   `style.css`: Estilos, animaciones y comportamiento responsivo.
*   `pvpLogo.png`: Logo oficial del torneo.

## 📝 Edición del contenido

Si necesitas modificar las reglas o las fechas, simplemente abre el archivo `index.html` y actualiza el texto entre las etiquetas HTML. Para modificar estilos (colores, tamaños, etc.), edita las variables o clases en el archivo `style.css`.
